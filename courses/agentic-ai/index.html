    About Agentic AI Zoomcamp

    Machine Learning Zoomcamp teaches you the complete machine learning engineering, covering the entire pipeline: from building models with Python to deploying them in production environments.

    Prerequisites

    You'll need:

    • Functional knowledge fo Python, data structures and LLMs
    • Comfort with command line basics

    Technical setup: For machine learning modules, you only need a laptop with an internet connection. For deep learning sections, we'll use cloud resources for more intensive computations.

    How to Join

    You can join ML Zoomcamp either by following a live cohort or learning at your own pace.

    All materials are freely available in this repository. Each module has its own folder directory. Lectures are pre-recorded and available in this YouTube playlist.

    Module Description
    Module 1: Foundations of Agentic AI and LLM Capabilities Explore what defines an agentic AI system and why leaders often lack a shared understanding of agents. Develop a consistent framework for evaluating opportunities and risks in a rapidly evolving agentic AI landscape.
    Module 2: Designing For Agentic AI Learn how agentic AI enables a shift from automation to transformation and reshapes how products, services, and workflows are designed and experienced.
    Module 3: Organizational and Agent Architecture Examine the organizational impact of deploying agentic AI within firms and across value chains
    Module 4: Measuring the Value of Agentic AI Develop the value proposition and measurement strategies to quantify the business impact of agentic AI systems.
    Module 5: AI Governance and Security Understand how to ensure agentic AI systems operate within legal, regulatory, and security boundaries while building trust and mitigating risk.
    Module 6: Decision Trees & Ensemble Learning Learn tree-based models and ensemble methods for better predictions.
